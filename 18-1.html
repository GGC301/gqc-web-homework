一、动画是怎么"动"起来的 三件事：逐帧、物理、绘制

① 逐帧循环

requestAnimationFrame 会在浏览器每次重绘前调用回调，大约每秒 60 次。 每帧算一次时间差 dt，用"每秒多少像素"乘上去，动画速度就与帧率无关。

② 重力加速与回弹

每帧执行 vy += g * dt、y += vy * dt，下落越来越快； 碰到目标位置时把速度反向并乘 0.26 的阻尼，就得到真实的弹跳，直到速度足够小才定格。

③ 绘制文字

fillText 负责画字，createLinearGradient 做渐变填充， shadowColor / shadowBlur 做发光；文字雨则把一串字符按 y 递减画出来，越靠上越淡。

二、核心代码 去掉样式后的骨架

/* ---------- 1. 高清屏适配：逻辑像素与物理像素分开 ---------- */ var dpr = Math.min(window.devicePixelRatio || 1, 2); canvas.width = width * dpr; canvas.height = height * dpr; ctx.setTransform(dpr, 0, 0, dpr, 0, 0); // 之后按 CSS 像素坐标画 /* ---------- 2. 逐帧循环 ---------- */ function frame(stamp) { var dt = Math.min(0.05, (stamp - last) / 1000); // 秒，限制最大值防跳帧 last = stamp; update(dt); draw(); requestAnimationFrame(frame); } /* ---------- 3. 重力 + 阻尼回弹 ---------- */ char.vy += 2400 * dt; // 加速度 char.y += char.vy * dt; // 位移 if (char.y >= char.targetY) { char.y = char.targetY; char.vy = -char.vy * 0.26; // 反向 + 衰减 if (Math.abs(char.vy) < 110) { // 弹不动了就定格 char.vy = 0; char.settled = true; } } /* ---------- 4. 渐变文字 + 光晕 ---------- */ var g = ctx.createLinearGradient(0, y - size / 2, 0, y + size / 2); g.addColorStop(0, '#a5f3fc'); g.addColorStop(0.5, '#818cf8'); g.addColorStop(1, '#f472b6'); ctx.font = '700 ' + size + 'px "Microsoft YaHei", sans-serif'; ctx.shadowColor = 'rgba(129,140,248,.85)'; ctx.shadowBlur = 24; ctx.fillStyle = g; ctx.fillText(char.ch, x, y);
