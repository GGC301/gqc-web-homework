# 实验目的（预期学习效果）

掌握前端的图像解决方案，尤其是字体图标和svg的图像解决方案，能够获得图像、使用图像和使用CSS修饰图像。

独立完成该四级项目，预期能获得和完成常见的网页中的图像，完成三级项目的导航设计。

# 实验任务及原理

使用现代工具iconfont.com网站，自动搜索、加工和生成相关字体文件和帮助文件，使用字体图标或SVG完成三级项目的下导航的设计，要求自适应宽度。

每位同学的项目内容默认为自己期末三级项目选题的下导航，如果所选项目没有下导航，可以选择其他导航或其他移动网站的下导航。

# 实验环境

实验仪器设备：PC

实验软件：Visual Studio Code或任何AI IDE

# 实验预习任务

完成iconfont.com网站的注册。

完成三级项目的选题，并将三级项目网站的下导航截图。

在iconfont网站获得图标并将其导出，在网页中使用。

在网页中使用字体图标或SVG，并改变其字体大小和颜色。

# 实验过程（实验方案）

获得字体图标或SVG图像。

根据每人所选的三级项目的图标的不同，获得相关图像资源，包括字体图标和SVG，推荐使用iconfont，获得的图标不要求和模仿实现的三级项目的图标完全一致。

实现自适应宽度的下导航的设计与实现。

使用字体图标或SVG ，要求和上一步中的技术有区别（如上一步用了字体图标，则这一步使用SVG），使用CSS修饰下导航，如果三级项目的下导航是固定的，实现固定效果。

测试

在多个浏览器、多个视口（viewport）中运行并查看效果，检查浏览器兼容性和自适应宽度。

提交和发布

完成实验报告，提交实验报告，文件名称为学号-姓名。

# 实验课后任务

完成和提交项目实验报告。
