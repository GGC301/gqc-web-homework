列表页负责"拿一批数据"，详情页负责"按 id 拿一条数据"。点击任意商品卡片即可跳到 17-3-detail.html?id=编号。

三、列表页的核心代码

// 列表：拿一批商品 async function yuan_load() { const yuan_res = await fetch('https://dummyjson.com/products?limit=8'); if (!yuan_res.ok) { throw new Error('HTTP ' + yuan_res.status); } const yuan_json = await yuan_res.json(); // 接口返回的是对象，商品数组在 products 里 console.log(yuan_json.total); // 总商品数 console.log(yuan_json.products); // 本页 8 条 yuan_render(yuan_json.products); } // 详情：按 id 拿一条，id 由跳转链接的查询字符串传入 // 17-3-detail.html?id=3 → location.search 为 "?id=3" var yuan_id = new URLSearchParams(location.search).get('id') || 1; fetch('https://dummyjson.com/products/' + yuan_id) .then(function (res) { return res.json(); }) .then(function (yuan_item) { console.log(yuan_item.title); });
