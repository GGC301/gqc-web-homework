一、图表里放了什么 数据取自智能客服的运营场景

双轴组合

会话量是"量"，解决率是"率"，单位不同就得用两个 yAxis，通过 yAxisIndex 把线挂到右轴。

堆叠柱状

机器人会话与人工会话用同一个 stack，柱子高度表示总量，分段颜色表示构成。

占比图

环形图用 radius: ['45%','70%'] 挖空中心；玫瑰图用 roseType: 'radius' 用半径表示大小。

响应式

图表容器宽度变化时调用 chart.resize()，否则窗口缩放后画布会被拉伸模糊。

二、怎么引入与初始化 本地文件，不走在线 CDN

<!-- 1. 引入：文件已下载到 cdn/echarts.min.js --> <script src="./cdn/echarts.min.js"></script> <!-- 2. 准备一个有宽高的容器 --> <div id="yuan_chart1" style="width:100%;height:380px"></div> <script> // 3. 初始化并设置配置项 var yuan_chart = echarts.init(document.getElementById('yuan_chart1')); yuan_chart.setOption({ tooltip: { trigger: 'axis' }, legend: { data: ['机器人会话', '人工会话', '解决率'] }, xAxis: { type: 'category', data: ['11-01', '11-02', '11-03', '11-04', '11-05', '11-06', '11-07'] }, yAxis: [ { type: 'value', name: '会话量' }, { type: 'value', name: '解决率', min: 70, max: 95, axisLabel: { formatter: '{value}%' } } ], series: [ { name: '机器人会话', type: 'bar', stack: 'total', data: [1280, 1420, 1356, 1680, 1520, 1180, 1340] }, { name: '人工会话', type: 'bar', stack: 'total', data: [320, 356, 298, 420, 386, 276, 312] }, { name: '解决率', type: 'line', yAxisIndex: 1, smooth: true, data: [82.4, 84.1, 83.6, 86.2, 85.1, 87.3, 86.5] } ] }); // 4. 窗口缩放时同步尺寸 window.addEventListener('resize', function () { yuan_chart.resize(); }); </script>
