一、Mermaid 的几个要点 文本即图形

语法即图形

用 flowchart TD 声明自上而下的流程图，用 A --> B 连边，改文本就等于改图，非常适合写进文档和代码仓库。

节点形状

A[矩形]、B(圆角)、C{菱形}、D([体育场])、E[(圆柱)]，形状本身就是语义。

ER 图的实体名

Mermaid 的 ER 实体名按标识符解析，中文要加引号："用户" ||--o{ "会话" : "发起"，不加引号会直接报解析错误。

字段与注释

实体块里写 类型 字段名 键 "注释"，键位支持 PK / FK / UK，注释用双引号包住。

三、怎么引入与渲染 本地文件，不走在线 CDN

<!-- 1. 引入：文件已下载到 cdn/mermaid/mermaid.min.js --> <script src="./cdn/mermaid/mermaid.min.js"></script> <!-- 2. 关掉自动渲染，自己控制时机与主题 --> <script> mermaid.initialize({ startOnLoad: false, theme: 'base', fontFamily: '"Microsoft YaHei", "PingFang SC", sans-serif', themeVariables: { primaryColor: '#eef2ff', primaryTextColor: '#1f2430', primaryBorderColor: '#818cf8', lineColor: '#94a3b8' }, flowchart: { curve: 'basis', useMaxWidth: true, htmlLabels: true } }); // 3. 用源码渲染出 SVG，再塞进容器 mermaid.render('yuan_mmd_flow', document.getElementById('yuan_flowSrc').textContent) .then(function (res) { document.getElementById('yuan_flowBox').innerHTML = res.svg; }) .catch(function (err) { console.error('Mermaid 渲染失败', err); }); </script>
