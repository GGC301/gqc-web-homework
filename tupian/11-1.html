Web 前端长度单位

CSS 中的长度单位分为绝对单位与相对单位两大类

一、绝对长度单位

单位 说明 换算关系
px 像素，最常用的单位 1in = 96px
cm 厘米 1cm ≈ 37.8px
mm 毫米 10mm = 1cm
in 英寸 1in = 2.54cm = 96px
pt 磅（打印排版单位） 1pt = 96/72 px ≈ 1.33px
pc 派卡 1pc = 12pt = 16px

二、相对长度单位

单位 相对于 典型用途
em 当前元素的父元素字号 段落内的间距、缩进
rem 根元素（html）字号 全局统一尺寸，避免层层继承
% 父元素对应尺寸 流式布局、宽度自适应
vw 视口宽度的 1% 大标题、全屏区块
vh 视口高度的 1% 首屏满屏布局
vmin 视口宽、高中较小值的 1% 横竖屏通用缩放
vmax 视口宽、高中较大值的 1% 横竖屏通用缩放
ch 字体中数字 "0" 的宽度 按字符数限制行宽
ex 字体中 x 的高度 与小写字母对齐

三、百分比 %（相对父元素）

父容器（.parent）
子元素 width: 50%

子元素宽度 = 父容器宽度 × 50%，父容器改变时子元素随之变化。

四、视口单位（vw / vh / vmin / vmax）

width: 50vw
width: 80vw
width: 10vmin
width: 40vmax
