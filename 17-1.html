JSON · 互联网上的"通用快递包裹"

JSON（JavaScript Object Notation）是一种纯文本的数据格式：前后端、各种语言都认识它。它只有 6 种数据类型，靠 {} 装对象、[] 装数组，一层层嵌套出任意复杂的数据。

一、JSON 是什么 用"寄快递"来理解

浏览器里的 JS 对象只活在内存里，一旦要"寄"出去（网络传输、存文件）就必须变成一段纯文本。JSON 就是这个约定好的打包格式：

1 · JS 对象内存里的数据，带函数、日期、undefined 都可以
→
2 · JSON.stringify()打包：对象 → JSON 字符串（纯文本，函数/undefined 被丢掉）
→
3 · 网络传输一段文本走 HTTP 传到服务器或浏览器
→
4 · JSON.parse()拆包：JSON 字符串 → 对象，可以正常取值了

二、JSON 的 6 种数据类型 比 JS 少得多，所以谁都认识

对象 object

花括号包起来的"键值对"，键必须加双引号。

{ "name": "关泉才" }

数组 array

方括号包起来的有序列表，下标从 0 开始。

[ "HTML", "CSS", "JS" ]

字符串 string

只能用双引号，不能用单引号、反引号。

"Hello JSON"

数字 number

整数、小数、负数都行，不能写 NaN / Infinity。

2026 / 98.5 / -12

布尔 boolean

只有两个值，全小写。

true / false

空 null

表示"什么都没有"，注意不是 undefined。

null

三、必须记住的语法规则 上排 ✓ 正确，下排 ✗ 错误

1. 键名必须双引号

JS 对象里可以不加引号，JSON 里不行。

{ "name": "关泉才" }
{ name: "关泉才" } ✗ 键名没引号

2. 字符串只能双引号

单引号、反引号在 JSON 里都是非法的。

{ "city": "北京" }
{ 'city': "北京" } ✗ 单引号非法

3. 不能写注释

JSON 是纯数据，不支持 // 或 /* */。

{ "age": 20 }
{ "age": 20 } // 年龄 ✗ 不能注释

4. 末尾不能多逗号

最后一项后面再加逗号会直接解析失败。

{ "a": 1, "b": 2 }
{ "a": 1, "b": 2, } ✗ 尾逗号

5. 没有 undefined / 函数

JS 特有的类型打包时会被丢掉或报错。

{ "tip": null }
{ "fn": function(){} } ✗ 函数不允许

6. 最外层是对象或数组

单独一个数字/字符串也算合法 JSON，但接口几乎都返回 {} 或 []。

{ ... } 或 [ ... ]
"只是个字符串" △ 极少这么用

五、两个核心方法 JSON.parse() / JSON.stringify()

JSON.parse(text)

拆包裹：字符串 → JS 对象 / 数组。文本不合法会抛异常，务必 try...catch。

var yuan_txt = '{"name":"关泉才","age":20}'; var yuan_obj = JSON.parse(yuan_txt); yuan_obj.name; // "关泉才" typeof yuan_obj; // "object"
运行结果

JSON.stringify(obj, replacer, space)

打包：对象 → 字符串。第三个参数控制缩进；函数、undefined 会被忽略。

var yuan_obj = { name: "关泉才", age: 20, say: function () {} }; JSON.stringify(yuan_obj); // 一行 JSON.stringify(yuan_obj, null, 2); // 缩进 2 空格 // say 函数被丢掉了
