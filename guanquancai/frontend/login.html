账号体系 · 服务端鉴权

登录你的账号，继续用 AI 干活

密码经 scrypt 加盐哈希后入库，明文不落库也不返回；登录成功后由服务端签发 HMAC-SHA256 签名 token， 前端只保存 token、不接触任何密钥。

  • 密码安全

    node:crypto scrypt + 16 字节随机盐，定长比较防时序攻击

  • 签名 token

    载荷含用户 ID、昵称与过期时间，服务端 HMAC 校验，默认 7 天有效

  • 统一响应

    注册 / 登录 / 校验 / 退出四个接口，全部 { code, msg, data } 格式
