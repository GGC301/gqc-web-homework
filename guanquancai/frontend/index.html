关于项目

开发约定与运行方式，详见根目录 AGENTS.md 与 readme.md。

技术栈

  • 前端：原生 HTML / CSS / JavaScript，零第三方库、零 CDN
  • 后端：Node.js 24 + Express 5，RESTful + MVC 分层，端口 8301
  • 数据库：SQLite（node:sqlite 内置驱动），10 张表，脚本可重建
  • 模型：DeepSeek-V4-Flash（对话）+ BAAI/bge-m3（向量）+ Qwen3-VL-8B（识图）

AI 功能（四个方向）

  • 基础聊天：messages 携带历史，超预算时把早期消息压成摘要继续对话
  • 知识库 RAG：解析 → 480 字切分 → 向量化 → 混合检索 Top-K → 带 [编号] 引用作答
  • 评论结构化：Excel 每 8 条一批判定好评/中评/差评，五字段 JSON + 饼图 + 精选
  • 识图 OCR：图片 base64 → 视觉模型 → 文档类型、金额、日期、关键词与全文

开发约定

  • CSS 类名、JS 变量/函数、数据库表名字段统一以 guan_ 开头
  • 接口统一前缀 /api，响应统一为 { code, msg, data }
  • 密钥与 token 签名密钥只存 backend/.env，前端不接触
  • 提示词、接口与建表 SQL 分别追加到 guanquancai_prompt.md、guan_interface.md、guan_database.md

运行方式

  • 安装依赖：cnpm i（失败改用 npm i），启动：npm start
  • 初始化：npm run initdb / initkb / initreview / inituser
  • 生成评论模拟数据：npm run genreview（写入项目根目录）
  • 访问 http://localhost:8301 ；测试账号 guanquancai / abc123456
