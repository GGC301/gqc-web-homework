本项目使用 SQLite，正常运行时无需手动连接；本页面用于验证后端能否正常访问数据库。 用户名与密码由后端读取 backend/.env 中的 DB_USER / DB_PASSWORD 后比对。

    相关接口

    接口明细见 backend/guan_interface.md，统一返回 { code, msg, data }。

    POST /api/db/test

    • 请求体：{ "guan_user": "root", "guan_password": "******" }
    • 成功：code = 0，返回数据库类型、版本与表内记录数
    • 失败：code = 4011（用户名或密码错误）/ 5003（连接失败）

    GET /api/db/info

    • 返回数据库类型、库名、主机与用户名（不含密码）
    • 用于本页下方“当前数据库配置”区域展示
