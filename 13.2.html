Lucide 图标（SVG 方式）

13.2 · 图标是内联 <svg> 矢量图形，脚本来自本地 cdn/lucide 目录，不请求任何外部网络

原理说明

Lucide 把每个图标存成一段 SVG 路径数据：页面里只写占位元素 <i data-lucide="house"></i>，引入本地的 lucide.min.js 后调用 lucide.createIcons()， 脚本会把每个占位元素替换成真正的 <svg> 内联进页面。 SVG 是矢量图形，描边使用 stroke="currentColor"， 可以直接用 CSS 控制宽高、颜色、描边粗细，也可以用 JS 随意操作。 

<script src="./cdn/lucide/lucide.min.js"></script>

<i data-lucide="house"></i>
<i data-lucide="heart"></i>

<script>
  lucide.createIcons();
</script>

SVG 特性演示

因为图标现在是真正的 SVG 元素，宽高、颜色、描边粗细都可以交给 CSS； 下面第三个示例还可以通过按钮用 JS 切换描边。

尺寸：width / height
颜色：color → stroke="currentColor"
描边：stroke-width（按钮切换）
