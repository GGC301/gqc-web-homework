    一、3D 图表是怎么搭起来的 场景 + 几何体 + 光照 + 交互

    四件套

    Scene 装东西，PerspectiveCamera 决定视角，WebGLRenderer 负责画到 canvas，再加环境光与方向光让立体感出来。

    柱状图

    每根柱子是一个 BoxGeometry，高度由数据换算；入场时把 scale.y 从 0 补间到 1，就是"长出来"的效果。

    3D 饼图

    圆柱体的 thetaStart / thetaLength 正好切出扇区：角度 = 占比 × 2π，留一点缝隙更清楚。

    交互

    拖动改变球坐标的方位角与俯仰角，滚轮改半径；Raycaster 把鼠标射线打进场景，命中哪块就高亮哪块。

    二、核心代码 关键几段

    /* ---------- 1. 渲染器 + 场景 + 相机 ---------- */ var renderer = new THREE.WebGLRenderer({ canvas: canvas, antialias: true, alpha: true }); renderer.setPixelRatio(Math.min(window.devicePixelRatio || 1, 2)); renderer.setSize(width, height, false); var scene = new THREE.Scene(); var camera = new THREE.PerspectiveCamera(42, width / height, 0.1, 200); /* ---------- 2. 柱状图：一个 Box 一根柱 ---------- */ var height = value / maxValue * 4.2; var bar = new THREE.Mesh( new THREE.BoxGeometry(0.7, height, 0.7), new THREE.MeshStandardMaterial({ color: 0x6366f1, metalness: 0.3, roughness: 0.35 }) ); bar.position.set(x, height / 2, 0); /* 生长动画：每帧把 scale.y 补间到 1 */ var p = Math.min(1, elapsed / 0.8); var ease = 1 - Math.pow(1 - p, 3); bar.scale.y = ease; bar.position.y = height * ease / 2; /* ---------- 3. 3D 饼图：圆柱扇区 ---------- */ var angle = item.value / total * Math.PI * 2; var slice = new THREE.Mesh( new THREE.CylinderGeometry(2.7, 2.7, thickness, 64, 1, false, start, angle - 0.03), new THREE.MeshStandardMaterial({ color: item.color, metalness: 0.25, roughness: 0.42 }) ); slice.position.y = thickness / 2; start += angle; /* ---------- 4. 球坐标环绕 + 射线拾取 ---------- */ camera.position.set( radius * Math.sin(phi) * Math.cos(theta), radius * Math.cos(phi), radius * Math.sin(phi) * Math.sin(theta) ); camera.lookAt(0, targetY, 0); raycaster.setFromCamera(pointer, camera); // pointer 归一化到 -1 ~ 1 var hits = raycaster.intersectObjects(targets, false);

    三、为什么用本地文件、用经典构建 file:// 下不能直接跑 ES Module

    <!-- 本地引入：文件已下载到 cdn/three/three.min.js（r149 经典构建） --> <script src="./cdn/three/three.min.js"></script> <script> // 直接拿到全局 THREE var scene = new THREE.Scene(); </script>

    现在官方主推 three.module.js + import，但直接用浏览器打开本地文件（file://）时， 模块脚本会因为跨域限制被拦截。本页因此采用经典构建，全局变量 THREE 拿来就用，双击 HTML 即可运行。
